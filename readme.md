# Boutique
Boutique is a framework for integrating server-side rendered Rust apps with Javascript.

## File structure
├─ public/
│  └─ robots.txt
└─ src/
   ├─ components/
   │  └─ button/
   │     ├─ index.css
   │     ├─ index.ts
   │     └─ mod.rs
   ├─ handlers/
   ├─ models/
   └─ views/
      └─ lander/
         ├─ lander.css
         └─ lander.rs
